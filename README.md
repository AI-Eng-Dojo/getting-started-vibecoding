# Claude Codeで作りたいものが確実にできあがる バイブコーディング実践入門

Claude Codeを使って、あなたのアイデアを4時間で「動くもの」にするハンズオンワークショップです。

## このワークショップで持ち帰れるもの

- **自分のアイデアが動いている状態のアプリ**（完成品としてREADME付き）
- 迷子にならずに作りきるための**3原則**（ゴールは一文で／見て、直す／動く状態を保つ）
- 詰まったときに必ず抜けられる**リカバリー3手**
- この先「スキル化・自動化・任せきる」へ進むための地図

## 対象者

- プログラミング経験は問いません（ターミナルを1度も触ったことがなくてもOK）
- 「作りたいものがある」または「作りたいものを見つけたい」人
- Claude Codeは未経験でOK。事前準備でセットアップします

本線（全員が通る道）は経験ゼロ前提で設計されています。経験者や進みの速い人には、各ハンズオンに **🚀拡張ミッション**（任意）が用意されており、CLAUDE.md・プランモード・Git運用・検証の自動化まで踏み込めます。**どこまでやっても、持ち帰るものは同じ「完成品と型」です。**

## 必要なもの

| 項目 | 要件 |
|---|---|
| PC | macOS / Windows / Linux。ブラウザとエディタが動けば十分 |
| Claudeプラン | **Pro（$20/月）以上が必須。Max推奨** |
| 事前準備 | **前日までに** [docs/00-prep.md](docs/00-prep.md) を完了（所要1時間） |

> **重要: 当日はワークショップ開始まで、Claude・Claude Codeの利用を控えてください。**
> 利用枠は「5時間ごとの枠」と「週ごとの枠」の二重構造で、チャットとClaude Codeで共有されています。
> 当日朝に使ってしまうと、ハンズオンの途中で上限に当たることがあります。
> 事前準備を前日までに済ませるのも同じ理由です。
