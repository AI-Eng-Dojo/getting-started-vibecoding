# demos/ — ライブデモのソース置き場

前編2「ライブデモ — ゼロから10分で1本」で講師が作ったもの、および事前配布するデモ動画のソースを開催回ごとに残す場所です。

## 構成ルール

```
demos/
├── README.md          ← このファイル
└── YYYY-MM-DD-⟨題材⟩/  開催回ごとのデモ成果物（例: 2026-09-01-recipe-picker/）
```

- デモは毎回ゼロから作るのが原則（完成品を見せる場ではなく、雑な指示→違和感→直すの過程を見せる場）
- 終わったらフォルダごとここに保存しておくと、次回のリハーサルやデモ動画の素材になる
- 参加者向けの参考実装（救済タグ）は [starters/](../starters/) 側のGitタグで管理する
