# demos/ — デモ動画のソース置き場

**前編にライブデモ枠はありません。**（4ハンズオンで2時間を使い切るため）
講師が「作るところ」を見せる機会は、**事前配布のデモ動画（10分）だけ**です。ここはそのソースを開催回ごとに残す場所です。

参加者向けの案内は [docs/00-prep.md](../docs/00-prep.md) の0.6にあります（任意の予習扱い）。

## 構成ルール

```
demos/
├── README.md          ← このファイル
└── YYYY-MM-DD-⟨題材⟩/  開催回ごとのデモ成果物（例: 2026-09-01-recipe-picker/）
```

- デモは毎回ゼロから作るのが原則（完成品を見せる場ではなく、**雑な指示から動くものが出るまでの過程**を見せる場）
- 動画に必ず入れる3点:
  1. 3行程度の雑な指示で動くものが出るところ（前編2の予告）
  2. スキルを1枚置いて、それがAIに読まれるところ（前編3の予告）
  3. 実装させる前に計画を読んで直させるところ（前編4の予告）
- 終わったらフォルダごとここに保存しておくと、次回のリハーサルや動画の差し替え素材になる
- 参加者向けの参考実装（救済タグ）は [starters/](../starters/) 側のGitタグで管理する
