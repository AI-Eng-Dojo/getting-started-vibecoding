# demos/ — デモ動画・参考実演のソース置き場

事前準備0.6で案内する「講師によるデモ動画」、および前半オープニングや待ち時間の解説で使う実演のソースを開催回ごとに残す場所です。

## 構成ルール

```
demos/
├── README.md          ← このファイル
└── YYYY-MM-DD-⟨題材⟩/  開催回ごとのデモ成果物（例: 2026-09-01-recipe-picker/）
```

- デモは毎回ゼロから作るのが原則（完成品を見せる場ではなく、雑な指示→違和感→直すの過程を見せる場）
- 終わったらフォルダごとここに保存しておくと、次回のリハーサルやデモ動画の素材になる
- 参加者向けの参考実装（救済版）は [starters/](../starters/) 側の `starters/⟨題⟩/rescue/index.html` で管理する（`main` 上のファイル。Gitタグは使わない）
