# 第0部 事前準備ガイド（所要1時間・前日までに完了）

当日100%手を動かすための準備です。**必ず前日までに完了させてください。**
理由は2つあります。

1. 当日つまずくと、その分あなたの「作る時間」が減ります
2. Claudeの利用枠は5時間ごとにリセットされる仕組みです。前日に準備を済ませておけば、当日は満タンの状態で開始できます

ゴールはひとつ: **Claude Codeが起動して、指示が1回通ること。**

---

## 0.1 アカウント準備（10分）

1. [claude.ai](https://claude.ai) でアカウントを作成（既にあればログイン確認のみ）
2. プランを確認します。**Pro（$20/月）以上が必須です。**
   - 快適に受講したい方、普段からClaudeチャットをよく使う方は **Max を推奨**します
   - 無料プランでは当日のハンズオン量をこなせません
3. 確認方法: claude.ai の設定画面 → プラン表示が「Pro」または「Max」になっていること

> **当日までの過ごし方（重要）**
> ワークショップ当日は、**開始時刻までClaude・Claude Codeを使わないでください。**
> チャットとClaude Codeは同じ利用枠を消費します。当日朝に別の作業で使うと、
> ハンズオン中に「上限に達しました」と表示されて手が止まることがあります。

## 0.2 10分セットアップ

Claude Codeには複数の入口があります。**迷ったらデスクトップアプリ**を選んでください（ターミナル操作が不要です）。

### 選択肢A: デスクトップアプリ（初心者推奨）

1. [claude.com/claude-code](https://claude.com/claude-code) からデスクトップアプリをダウンロード
2. インストールして起動し、claude.aiのアカウントでログイン

### 選択肢B: CLI（ターミナルに慣れている人向け）

1. ターミナルを開いてインストールコマンドを実行:

```bash
npm install -g @anthropic-ai/claude-code
```

2. 任意の作業フォルダで起動し、ブラウザ経由でログイン:

```bash
claude
```

> インストール方法は変わることがあります。うまくいかない場合は公式ドキュメント
> （[docs.claude.com/claude-code](https://docs.claude.com/en/docs/claude-code/overview)）の手順を正としてください。

## 0.3 動作確認ミッション（15分）

セットアップ確認を兼ねて、最初の1本を作ってしまいます。

1. デスクトップの適当な場所に空のフォルダ `vibe-warmup` を作り、Claude Codeでそのフォルダを開く
2. 次の指示をそのまま貼り付ける:

```text
ブラウザで遊べるじゃんけんゲームを、1つのHTMLファイルで作ってください。
グー・チョキ・パーのボタンを押すとコンピュータと勝負でき、勝敗と通算成績が表示されるようにしてください。
できたらファイルをブラウザで開く方法を教えてください。
```

3. 途中で**権限の確認**（「このファイルを作成してもよいですか?」のような質問）が出たら、内容を読んで許可してください。
   - これはClaude Codeの安全装置です。Claudeはあなたの許可なくファイルを作ったりコマンドを実行したりしません
   - 何を聞かれているか分からなかったら、そのまま当日質問してください（当日冒頭で解説します）
4. できあがったHTMLファイルをブラウザで開き、じゃんけんが遊べることを確認

## 0.4 ハンズオンリポジトリの入手（10分）

当日使うスターター一式は、**このリポジトリそのもの**です。手元のPCに取得してください。

- Gitに慣れている人:

```bash
git clone https://github.com/AI-Eng-Dojo/getting-started-vibecoding.git
```

- Gitに慣れていない人: GitHubのリポジトリページで「Code」→「Download ZIP」からダウンロードして展開すればOKです
- 中身: お題テンプレート3種の開始状態（[starters/](../starters/)）＋詰まったとき用の「救済タグ」（各段階の参考実装）

> 救済タグとは: ハンズオンの各段階に対応した「ここまでできている状態」のスナップショットです。
> 当日どこかで完全に詰まっても、該当タグの状態から再開すれば絶対に置いていかれません。
> 使い方は [starters/README.md](../starters/README.md) にまとめてあります。

## 0.5 つまずき早見表

| 症状 | 対処 |
|---|---|
| `claude: command not found` | ターミナルを開き直す。それでもダメならNode.js（v18以上）が入っているか確認 |
| ログインのブラウザが開かない | 表示されたURLを手動でブラウザに貼り付ける |
| 権限プロンプトで固まった | 内容を読んで「許可」。判断に迷うものは前日ならスキップし当日質問でOK |
| 「上限に達しました」と出た | 5時間待てば回復します。前日中なら問題なし。当日出さないために0.1の注意を守ってください |
| 会社PCでプロキシに阻まれる | 個人PCでの参加を推奨。難しければ事前に主催者へ連絡 |
