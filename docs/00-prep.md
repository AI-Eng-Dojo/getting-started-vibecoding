# 第0部 事前準備ガイド（所要60〜90分・前日までに完了）

当日100%手を動かすための準備です。**必ず前日までに完了させてください。**
理由は2つあります。

1. 当日つまずくと、その分あなたの「作る時間」が減ります
2. Claudeの利用枠は一定時間で回復する仕組みです。前日に準備を済ませておけば、当日を良い状態で始められます

ゴールはひとつ: **Claude Codeが起動して、指示が1回通ること。**

> **所要時間の目安**
> 手順そのものは45分ぶんです。ただし**初めての方は90分見てください。**
> アカウント作成・支払いの反映待ち・インストール・フォルダ操作で時間を取られます。
> 30分以上どこかで止まったら、それ以上粘らずに0.5を見て、それでもダメなら提出フォームに状況を送ってください。

## 0.1 アカウント準備（15分・全員必須）

1. [claude.ai](https://claude.ai) でアカウントを作成（既にあればログイン確認のみ）
2. プランを確認します。**Pro（$20/月）以上が必須です。**
   - 快適に受講したい方、普段からClaudeチャットをよく使う方は **Max を推奨**します
   - 無料プランでは当日のハンズオンを完走できません
3. 確認方法: claude.ai の設定画面 → プラン表示が「Pro」または「Max」になっていること

> **アカウントの取り違えに注意（毎回いちばん多いつまずきです）**
> - **当日使うものと同じアカウント**でログインしてください
> - 仕事用と個人用など複数のアカウントを持っている人は、**どちらで課金したかをメモ**しておいてください
> - 課金直後は反映に少し時間がかかることがあります。プラン表示が「Pro」または「Max」に変わったことを**目で確認するまで**、準備完了にしないでください

> **当日までの過ごし方（重要）**
> ワークショップ当日は、**開始時刻までClaude・Claude Codeを使わないでください。**
> チャットとClaude Codeは同じ利用枠を消費します。当日朝に別の作業で使うと、
> ハンズオン中に「上限に達しました」と表示されて手が止まることがあります。

## 0.2 セットアップ（20分・全員必須）

Claude Codeには複数の入口があります。**迷ったらデスクトップアプリ**を選んでください（ターミナル操作が不要です）。

### 選択肢A: デスクトップアプリ（初心者はこちら）

1. [claude.com/claude-code](https://claude.com/claude-code) からデスクトップアプリをダウンロード
2. インストールして起動し、claude.aiのアカウントでログイン

これで完了です。0.3へ進んでください。

### 選択肢B: CLI（ターミナルに慣れている人向け）

**前提: Node.js（v18以上）が入っていること。** 入っていない場合は先に入れてください。

```bash
# 入っているかの確認（バージョンが表示されればOK）
node -v
```

表示されなければ [nodejs.org](https://nodejs.org/) からインストールするか、選択肢Aに切り替えてください。**前日にNode.jsの導入で消耗するくらいなら、デスクトップアプリで参加するほうが確実です。**

```bash
npm install -g @anthropic-ai/claude-code
```

任意の作業フォルダで起動し、ブラウザ経由でログインします。

```bash
claude
```

> インストール方法は変わることがあります。うまくいかない場合は公式ドキュメント
> （[docs.claude.com/claude-code](https://docs.claude.com/en/docs/claude-code/overview)）の手順を正としてください。

### Windowsの人へ

- **まずデスクトップアプリ（選択肢A）を選んでください。** 当日はCLIの復旧に時間を使えません
- CLIを使う場合は PowerShell で実行します。`npm` が見つからないと言われたらNode.jsが未導入です
- インストール後に `claude` が見つからない場合は、**PowerShellを開き直して**ください。それでもダメなら選択肢Aに切り替えて、当日質問してください

## 0.3 動作確認ミッション（20分・全員必須）

セットアップ確認を兼ねて、最初の1本を作ってしまいます。

### 1. 作業用のフォルダを作る

デスクトップに `vibe-warmup` という名前の空フォルダを作ります。

- **macOS**: デスクトップ上で右クリック →「新規フォルダ」→ 名前を `vibe-warmup` にする
- **Windows**: デスクトップ上で右クリック →「新規作成」→「フォルダー」→ 名前を `vibe-warmup` にする

### 2. そのフォルダをClaude Codeで開く

- **デスクトップアプリの人**: アプリを起動すると作業フォルダを選ぶ操作があります。いま作った `vibe-warmup` を選んでください
- **CLIの人**: ターミナルでそのフォルダに移動してから `claude` と入力します

> フォルダを選ぶ操作が見つからない場合は、**そこで止めて構いません。**
> 画面のスクリーンショットを撮り、0.5の提出とあわせて送ってください。当日開始前に対応します。

### 3. 指示を出す

次の指示をそのまま貼り付けてください。

```text
ブラウザで遊べるじゃんけんゲームを、1つのHTMLファイルで作ってください。
グー・チョキ・パーのボタンを押すとコンピュータと勝負でき、勝敗と通算成績が表示されるようにしてください。
できたらファイルをブラウザで開く方法を教えてください。
```

途中で**権限の確認**（「このファイルを作成してもよいですか?」のような質問）が出たら、内容を読んで許可してください。

- これはClaude Codeの安全装置です。Claudeはあなたの許可なくファイルを作ったりコマンドを実行したりしません
- 何を聞かれているか分からなかったら、そのまま当日質問してください（当日冒頭で解説します）

### 4. ブラウザで動かす

できあがったHTMLファイルをブラウザで開き、じゃんけんが遊べることを確認します。ファイルの場所が分からなくなったら、**Claude Codeに「作成したHTMLファイルの場所を教えて」と聞いてください。**

### 5. `/status` を1回打っておく（30秒）

当日、前編と後編の開始時にこのコマンドを使います。**ここで一度だけ練習しておいてください。**

Claude Codeの入力欄に `/status` と入力して送信します。利用枠の残量などが表示されれば成功です。当日は「これを打ってください」と言われるだけなので、いま一度打っておくと迷いません。

## 0.4 ハンズオンリポジトリの入手（10分・全員必須）

当日使う課題一式は、**このリポジトリそのもの**です。手元のPCに取得してください。

- **Gitに慣れている人**:

```bash
git clone https://github.com/AI-Eng-Dojo/getting-started-vibecoding.git
```

- **Gitに慣れていない人**: GitHubのリポジトリページで「Code」→「Download ZIP」からダウンロードして展開すればOKです。展開したフォルダは**デスクトップなど分かる場所に置いてください**（当日「どこに展開したか分からない」が起きます）

中身は次の2つです。

- **中級課題3種の課題仕様**（[starters/](../starters/)）— 前編で使います。**最初はHTMLファイルは入っていません。**課題の条件が書かれたREADMEだけが入っていて、実装は当日あなたが作ります
- **詰まったとき用の「救済タグ」**（各課題の完成例）

> **救済タグとは**: 課題ごとの「完成している状態」のスナップショットです。
> 当日どこかで完全に詰まっても、そこから再開すれば置いていかれません。
> **Gitを使う人にもZIPで取得した人にも、それぞれの手順を用意しています。**
> 使い方は [starters/README.md](../starters/README.md) にまとめてあります（当日でも間に合います）。

## 0.5 つまずき早見表

| 症状 | 対処 |
|---|---|
| `claude: command not found` | ターミナル（PowerShell）を開き直す。それでもダメならNode.js（v18以上）が入っているか `node -v` で確認 |
| `npm: command not found` | Node.jsが未導入です。前日ならデスクトップアプリ（選択肢A）に切り替えるのがいちばん速い |
| `EACCES` / `permission denied` が出る | グローバルインストールの権限の問題です。前日は深追いせず、デスクトップアプリに切り替えてください |
| ログインのブラウザが開かない | 表示されたURLを手動でブラウザに貼り付ける |
| Claude Codeでフォルダを開く操作が分からない | そこで止めてOK。スクリーンショットを撮って提出フォームへ。当日開始前に対応します |
| 作ったHTMLファイルが見つからない | Claude Codeに「作成したHTMLファイルの場所を教えて」と聞く |
| ZIPを展開した場所が分からない | もう一度ダウンロードし、**デスクトップに**展開し直すのが早い |
| 権限プロンプトで固まった | 内容を読んで「許可」。判断に迷うものは前日ならスキップし当日質問でOK |
| 「上限に達しました」と出た | 時間をおけば回復します。前日中なら問題なし。当日出さないために0.1の注意を守ってください |
| 会社PCでプロキシや証明書に阻まれる | 個人PCでの参加を推奨します。個人PCがない場合は**事前に主催者へ連絡してください**。ブラウザだけで動くWeb版に切り替えるなど、当日の代替手段を用意します |
