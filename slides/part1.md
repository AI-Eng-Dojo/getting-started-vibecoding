# 前半 バイブコーディングをはじめよう

3時間で、作る体験から自分のアイデアの具体化まで進めます。

- Claude Codeに頼み、動くアプリを確認する
- Gmailとつなぎ、下書きを作る
- 自分のアイデアを `myapp` のREADMEに残す
- 質問と記録の作法をエージェントスキルにし、宿題で仕様へ育てる

[教材で手順を見る](../docs/01-part1.md#やること)

## 1. バイブコーディングの進め方

オープニングは10分です。
作りたいものを言葉で伝え、動く画面を見ながら直します。

1. 作りたいものをClaude Codeに伝える
2. できたものをブラウザで開き、自分で操作する
3. 違うところを具体的に伝えて直す

コードを書いた経験がなくても、画面の表示と動作で判断できます。

[教材で手順を見る](../docs/01-part1.md#バイブコーディングとは)

## 1. Claude Codeを動かす4つの要素

| 要素 | 役割 |
|---|---|
| モデル | 指示を受け取り、応答や使うツールを考える |
| ツール | ファイル編集やコマンド実行を行う |
| コンテキスト | 会話、ファイル、実行結果を次の応答に渡す |
| 権限 | 実行時に確認する操作を決める |

Claude Codeは、対話とツールの実行を繰り返して作業を進めます。

[教材で手順を見る](../docs/01-part1.md#claude-codeはどう動いているのか)

## 1. 最初に試すコマンド

**前半・後半共通の推奨は Sonnet × medium です。**

- `/help` で使えるコマンドを、`/status` で現在の状態を確認する
- `/model sonnet` でSonnetを選ぶ
- `/effort medium` で考える深さを `medium` にする
- `/usage` で利用枠を確認する
- `/permissions` で許可した操作を確認する

入力欄に `/` を打つと候補が出ます。

[教材で手順を見る](../docs/01-part1.md#基本的なスラッシュコマンドを試す)

## 1. 実行を許可するモード

| モード | 確認のしかた |
|---|---|
| Manual Mode | ツールを使うときに確認する |
| Accept Edits ON | ファイル編集を自動承認し、ほかの操作は確認する |
| Auto Mode | AIがリスクを判定する。今日はこれを使う |
| Plan Mode | 変更する前に計画を確認する |

`/config` またはShift+Tabで切り替えます。
Auto Modeでも確認が出たときは、操作内容を読んで判断してください。

## 4. tsumetsumeに質問の作法を書く

- 質問は一度に一つ。回答を受け取ってから次へ進む
- 各質問に、おすすめの答えを添える
- 調べれば分かる事実はClaudeが確認する
- 何を選ぶかという決定は、使う人に委ねる

`description` には「いつ使うか」を書きます。
普段打ちそうな言葉を入れ、本文に質問の進め方を書いてください。

[教材で手順を見る](../docs/01-part1.md#①-tsumetsume-を作る-一問ずつ問い詰める)

## 4. dddに記録の作法を書く

質問の途中で決まった内容を、後から読める形にします。

- **CONTEXT.md**：確定した用語と、その意味を残す
- **ADR**：あとから変えるのが大変な決定と、その理由を残す
- ADRの保存先は `docs/adr/`
- 最後にまとめず、決まったときに書く

該当する決定がなければ、ADRが0本でも構いません。

[教材で手順を見る](../docs/01-part1.md#②-ddd-を作る-決まったことを書き残す)

## 6. ファイルが出てこなかったとき

問答の最後に、書き出しを頼みます。

```text
ここまで詰めた内容を、README.md と TASKS.md に書き出してください。
README.md: 何を作るか、誰が使うか、できること、今回やらないこと、完成判定。
できることは3〜5個を目で確認できる形にし、今回やらないことには理由を一行ずつ付けてください。
TASKS.md: 実装する順に並べ、1件を15分以内で終わる大きさにしてください。
各タスクに、画面のどこを見れば終わったと分かるかという完了定義を書いてください。
途中で止まっても動くものが残る順番にしてください。
```

## 6. 後半前日までの宿題提出

- 案内された提出フォームへ `README.md` と `TASKS.md` を送る
- `CONTEXT.md` とADRは提出不要。手元の `myapp` に残す
- 後半は同じ `myapp` を開き、今日やる分を選ぶところから再開する
- 宿題が揃わなくても、後半7に習慣トラッカーの見本がある

後半は2時間55分です。
実装、レビュー、公開まで進めます。
