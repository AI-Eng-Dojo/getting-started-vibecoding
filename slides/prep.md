# 事前準備

前日までに、自分のPCでClaude Codeが動く状態を作ります。
セルフペースで進めてください。

- アカウントを用意する
- じゃんけんゲームを作り、ブラウザで動かす
- Gitの公開情報とGitHubへのログインを確認する
- チェックポイント0の提出物を送る

[教材で手順を見る](../docs/00-prep.md#事前準備ガイド)

---

## 0.0 用意するソフトウェア

- VS CodeとClaude Code拡張を使う
- Node.jsのLTS版を全OSで入れる（`wrangler`・Backlog用）
- **Git**で変更を保存し、**GitHub CLI（gh）**でGitHubを操作する
- 作ったHTMLを確認するブラウザを用意する

コマンドの操作はClaude Codeに頼めます。
事前準備では、実行できる状態まで確認します。

[教材で手順を見る](../docs/00-prep.md#00-必要なもの一覧)

---

## 0.1 用意するアカウント

| アカウント | この講座での用途 |
|---|---|
| Claude | Pro以上で参加。Max推奨 |
| GitHub | 自分のリポジトリを当日作る |
| Google（Gmail） | Gmail連携・Cloudflareアカウント作成に使用。見学＋アカウントなし公開なら不要 |
| Cloudflare | 公開したアプリを残す場合に使う。任意 |
| NotionまたはBacklog | 後半のタスク引き渡し。任意 |

Backlogを選ぶ人は、前日までにログイン、APIキー発行、`node -v` の確認を済ませます。

[教材で手順を見る](../docs/00-prep.md#01-アカウント準備)

## 0.1 Claudeの設定と利用枠

- Claudeにログインし、利用プランを確認する
- 「設定」→「プライバシー」で「AIモデルの改善にご協力ください」をOFFにする
- 会社のPCやアカウントは、社内ルールに沿って使う
- 当日は開始まで利用を控え、ハンズオン用の利用枠を残す

利用枠はチャットとClaude Codeで共有されます。
料金やプランの詳細は、教材から公式ページで確認してください。

[教材で手順を見る](../docs/00-prep.md#①-claudeのアカウントとプラン)

## 0.2 Claude Codeを起動する

1. VS Codeを入れ、1.94.0以上であることを確認する
2. Claude Code拡張を入れる
3. Node.jsのLTS版（22以上）を入れ、PCを再起動する
4. 拡張からClaudeにログインし、一言送る

```text
こんにちは。動作確認です。
```

返答が来たら、次のじゃんけんゲームで動作を確認します。

[教材で手順を見る](../docs/00-prep.md#02-開発環境のセットアップ)

## 0.3 じゃんけんゲームで動作確認

空の `claude-test` フォルダをVS Codeで開き、`README.md` を作ります。

```markdown
# じゃんけんゲーム
- HTMLファイル1つで動くブラウザゲーム
- グー、チョキ、パーを選ぶと、相手がランダムに手を出し、勝敗を表示する
```

Claude Codeに「READMEに書かれているものを実装して」と頼みます。
できたHTMLをブラウザで開き、選んだ手に応じて勝敗が出るか確認してください。

[教材で手順を見る](../docs/00-prep.md#03-動作確認)

## 0.4 Gitに残る名前とメールアドレス

まずClaude CodeにGitが使えるか確認してもらいます。
コミットには、作成者の名前とメールアドレスが残ります。
続けて現在の値を確認します。

```text
git config --get user.name と git config --get user.email を実行して、
結果をそのまま見せてください。まだ何も変更しないでください。
```

- 名前は公開されても困らないものにする
- メールはGitHubの「Settings → Emails」でnoreplyアドレスを控える
- 変更するときは自分で控えた値を渡し、設定後の値も確認する

[教材で手順を見る](../docs/00-prep.md#04-gitとgithub-clighの準備)

---

## 0.4 GitHub CLIのログイン

```text
このPCでGitHub CLI（ghコマンド）が使える状態か確認してください。
使えない場合は、このOSに合ったインストール方法を教えてください。
インストールできたら、gh auth login でログインする手順も教えてください。
```

- `gh auth status` が成功し、自分のユーザー名が出れば準備完了
- 実行結果はチェックポイント0に提出する
- `gh` が使えない場合は、当日ブラウザで作成してGitでcloneする方法も使える

[教材で手順を見る](../docs/00-prep.md#③-github-clighにログインする)

## 0.6 起動や認証で止まったら

- 認証画面が開かなければ、表示されたURLをブラウザに貼る
- 拡張が動かなければ、VS Codeが1.94.0以上か確認する
- Claude Code拡張を更新し、VS Codeを再起動する

解消しなければ、エラー文と画面を残してCLI版を試します。
まず `node -v` でNode.jsが22以上か確認してください。

```bash
npm install -g @anthropic-ai/claude-code
claude
```

未解決でも、その状態を添えて提出できます。

[教材で手順を見る](../docs/00-prep.md#06-つまずき早見表)

うまくいかなかった場合も、スクリーンショットと状況を添えて提出してください。
