# ハンズオン説明用スライド

画面共有やプロジェクターで、ハンズオンの流れと各演習の進め方を説明するためのスライドです。
操作の詳しい手順やコピーするプロンプトは、各スライド下部の「教材で手順を見る」から開けます。

| スライド | 範囲 | 時間の目安 |
|---|---|---|
| [事前準備を開く](prep.md) | アカウント、開発環境、動作確認、チェックポイント0 | 前日までに各自で準備 |
| [前半を開く](part1.md) | Claude Codeの基礎、MCP、自作Skill、アイデアの具体化、宿題 | 3時間 |
| [後半を開く](part2.md) | MVPの選定、実装、レビュー、公開、仕事の道具への引き渡し | 2時間55分 |

## スライドの操作

| 操作 | キーまたは画面上の操作 |
|---|---|
| 次へ、前へ | 矢印キー、Page Down / Page Up、画面下のボタン |
| 最初、最後へ | Home / End |
| 指定のスライドへ | スライド選択メニュー |
| 全画面の切り替え | F または全画面ボタン |
| 全スライドを一覧で読む | O または一覧ボタン |
| 印刷、PDFとして保存 | ブラウザの印刷機能。横向きで全スライドを印刷できます |

URLの末尾にある `#slide-番号` を共有すると、そのスライドから開けます。
スマートフォンでもボタンで操作できます。
