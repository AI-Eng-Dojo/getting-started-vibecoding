# starters/ — 中級課題（前編ハンズオン③）

前編ハンズオン③（[docs/01-part1.md](../docs/01-part1.md) の4章）で使う中級課題です。

ハンズオン①のテトリスは3行の指示で作りました。ここでは**課題仕様（README）から実行計画を立てさせ、計画を読んでから実装させます。**

## 使い方

1. 3つから1つ選ぶ（迷ったらA）
2. 選んだフォルダをClaude Codeで開く
3. 前編テキスト4章の指示文を貼り付けて、**まず実行計画だけ**を出させる
4. 計画を自分の目で読み、納得してから実装させる

| 課題 | フォルダ | こんな人に | 段取りの重さ |
|---|---|---|---|
| A: ポモドーロタイマー | [a-pomodoro-timer/](a-pomodoro-timer/) | 迷ったらこれ | 軽い |
| B: 診断チャート | [b-shindan-chart/](b-shindan-chart/) | コンテンツを作るのが好き | 中くらい |
| C: 習慣トラッカー | [c-habit-tracker/](c-habit-tracker/) | データが残るアプリを作りたい | 重い |

各フォルダの README には「できあがりの条件」「制約」「やらなくていいこと」が書いてあります。**最初はHTMLファイルは入っていません。**あなた（とClaude）がこれから作ります。

## 詰まったときの救済ルート

各課題の**完成例**を、Gitのタグとして用意しています。当日どこかで完全に詰まったら、そこから再開してください。**「戻って進む」は正規の技術です。**

タグ名は `rescue/handson3-⟨課題⟩` の形式です（`rescue/handson3-a` / `-b` / `-c`）。

### Gitを使っている人

**タグを直接 checkout しないでください。**作業中のファイルが見えなくなります。かならず作業用のブランチを作って移動します。

```bash
# 完成例から新しい作業場所を作る（以降の変更はこのブランチに残る）
git switch -c rescue-work rescue/handson3-a
```

`starters/a-pomodoro-timer/index.html` が完成例です。ブラウザで開いて動作を確認し、そこから続きを進めてください。

元の状態に戻りたくなったら `git switch main` です。

### ZIPでダウンロードした人（Gitを使っていない人）

Gitコマンドは不要です。ブラウザで次のURLを開くと、完成例入りのZIPをダウンロードできます。

```
https://github.com/AI-Eng-Dojo/getting-started-vibecoding/archive/refs/tags/rescue/handson3-a.zip
```

**このZIP1つに3課題ぶんの完成例が入っています。**（末尾を `-b` `-c` に変えても中身は同じです）
展開したら、自分が選んだ課題のフォルダ `starters/⟨課題フォルダ⟩/index.html` をブラウザで開いてください。

**URLが分からなくなったら、その場でメンターに聞いてください。**当日はメンターが同じものをその場で配れるようにしています。

> 運営メモ: 救済タグは各開催回の前に `git push origin --tags` で公開まで済ませること。
> タグが未push だと、上記のZIP URLは404になり、ZIP参加者の救済ルートが丸ごと機能しない。
