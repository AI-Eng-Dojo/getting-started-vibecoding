# starters/ — ハンズオン①のお題テンプレート

前編ハンズオン①（[docs/01-part1.md](../docs/01-part1.md)）で使う、お題3種の開始状態フォルダです。

## 使い方

1. 3つから1つ選ぶ（迷ったらA）
2. 選んだフォルダをClaude Codeで開く
3. フォルダ内READMEの指示文をそのまま貼り付けて実行

| お題 | フォルダ | こんな人に |
|---|---|---|
| A: ポモドーロタイマー | [a-pomodoro-timer/](a-pomodoro-timer/) | 迷ったらこれ |
| B: 診断チャート | [b-shindan-chart/](b-shindan-chart/) | コンテンツを作るのが好き |
| C: 習慣トラッカー | [c-habit-tracker/](c-habit-tracker/) | データが残るアプリを作りたい |

## 救済タグ

ハンズオンの各段階に対応した「ここまでできている状態」のスナップショットを、Gitタグとして用意します。当日どこかで完全に詰まったら、該当タグの参考実装から再開してください（「戻って進む」は正規の技術です）。

```bash
# タグの一覧を見る
git tag -l 'rescue/*'

# 例: ハンズオン①完了時点のお題Aの状態を見る
git checkout rescue/handson1-a
```

> 運営メモ: 救済タグは各開催回の前に整備します。タグ名は `rescue/handson⟨番号⟩-⟨お題⟩` の形式。
