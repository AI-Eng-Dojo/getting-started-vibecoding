# 中級課題A: ポモドーロタイマー

作業と休憩を交互に繰り返す、集中用のタイマーを作ります。

このフォルダをClaude Codeで開き、**まず実行計画だけ**を立てさせてください（指示文は[前編テキスト 4章](../../docs/01-part1.md)にあります）。計画を読んで納得してから実装させます。

## 作るもの

ブラウザで動く、1つのHTMLファイルで完結したポモドーロタイマー。

## できあがりの条件

**自分の目で確認できるもの**だけを条件にしています。上から順に、1つずつ動かしながら進めてください。

1. **残り時間が大きく表示される** — 画面の中央に、離れていても読める大きさで `25:00` の形式で出る
2. **開始・一時停止・リセットができる** — 開始で減り始める。一時停止でその場で止まる。リセットで25:00に戻る
3. **作業と休憩が自動で切り替わる** — 25分の作業が終わると自動で5分の休憩に入り、休憩が終わると次の作業に戻る。いま作業中か休憩中かが画面で分かる
4. **時間が来たら音で知らせる** — 切り替わる瞬間に音が鳴る（音声ファイルは使わず、ブラウザの機能で鳴らすこと）
5. **完了したポモドーロの数が出る** — 作業を1回終えるたびに数が増え、画面に表示される

## 制約

- **1つのHTMLファイルで完結させること。** 別ファイルのCSSやJavaScript、外部から読み込むライブラリは使わない
- インターネットに接続していなくても動くこと
- 25分・5分の長さは変更できなくてよい

## やらなくていいこと

時間が余ったら考えても構いませんが、条件には含めません。

- 作業時間・休憩時間を設定画面から変えられるようにする
- 日をまたいだ記録を残す
- 通知（ブラウザ通知）を出す

## 動作確認のコツ

25分待っていられないので、**確認のときは秒数を短くしてもらってください。** 「確認したいので、作業5秒・休憩3秒に一時的に変えて」と頼み、切り替わりと音と件数を見てから元に戻させます。
