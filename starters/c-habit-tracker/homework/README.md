# 習慣トラッカー

毎日つづけたい習慣を登録して、今日やったかどうかをチェックし、直近7日の達成状況が一目で分かるアプリ。

## 誰が使うか

「筋トレ」「読書」「日記」のような習慣を続けたいが、**続いているのかどうかが感覚でしか分からない**人。自分ひとりで使う。PCのブラウザで、1日1回開く。

## できること

1. 入力欄に習慣名を入れて「追加」を押すと、下の一覧にその習慣の行が増える
2. 一覧の「今日」の列を押すとチェックが入り、もう一度押すと外れる
3. 一覧に直近7日分の日付が列として並び、チェックした日には印が表示される
4. ブラウザを閉じて開き直しても、登録した習慣とチェックの状態が残っている
5. 行の「削除」を押すと、その習慣が一覧から消える

## 今回やらないこと

- **7日より前の履歴を見る** — 画面が横に広がるわりに、「続いているか」は7日で十分分かるため
- **連続達成日数（ストリーク）の表示** — 「できること」1〜4が動いてからでよい仕上げのため
- **目標回数の設定・リマインド通知** — 通知は「ブラウザだけで動く」範囲を超えるため
- **他の端末との同期・共有** — ログインとサーバーが必要になるため
- **見た目のデザイン（配色・アイコン・アニメーション）** — 動くようになってから最後に回すため

## データをどう扱うか

**ブラウザに保存する（閉じても残る）。** 保存先はこのブラウザの中だけで、サーバーには送らない。保存が使えない環境（プライベートウィンドウなど）では、**記録が残らないことを画面に出す。**

## 完成判定

- 習慣を2つ追加して、両方が一覧に行として並んでいる
- 片方の「今日」を押すと印が付き、もう一度押すと外れる
- ブラウザのタブを閉じて開き直しても、その2つとチェックの状態がそのまま残っている
