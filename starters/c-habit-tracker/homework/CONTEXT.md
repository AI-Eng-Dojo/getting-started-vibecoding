# 習慣トラッカー

毎日つづけたい習慣を登録し、今日やったかどうかを記録して、直近7日の達成状況を一目で見るための用語集。`tsumete` が仕様を詰めるあいだに呼び出した `ddd` が書き残したもの。

## 言葉

**習慣**:
利用者が毎日つづけたいと決めた行動。「筋トレ」「読書」のように名前で登録し、一覧の1行になる。
_避ける_: タスク、目標、項目

**チェック**:
ある習慣を、ある日にやったという記録。今日の分だけ付けたり外したりできる。
_避ける_: 完了、達成、done

**印**:
チェックが付いた日に、一覧のその日の列へ表示されるしるし。チェックは記録で、印はその表示。
_避ける_: チェックマーク、アイコン

**直近7日**:
今日を含む過去7日分。一覧に日付の列として並ぶ範囲で、これより前は表示しない。
_避ける_: 今週、履歴、カレンダー

**一覧**:
登録した習慣が1行ずつ並び、直近7日の列を持つ表。画面の中心にあるもの。
_避ける_: リスト、テーブル

**ブラウザ保存**:
習慣とチェックを、いま使っているブラウザの中に残すこと。閉じても消えないが、他の端末には写らない。
_避ける_: セーブ、同期、クラウド
