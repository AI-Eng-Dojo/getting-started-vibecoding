# 中級課題C: 習慣トラッカー

毎日の習慣を記録し、直近1週間の達成状況が一覧で見えるアプリを作ります。

このフォルダをClaude Codeで開き、**まず実行計画だけ**を立てさせてください（指示文は[前編テキスト 4章](../../docs/01-part1.md)にあります）。計画を読んで納得してから実装させます。

## 作るもの

ブラウザで動く、1つのHTMLファイルで完結した習慣トラッカー。

3つの課題のなかで、**いちばん段取りが要る課題**です。「データをどう持つか」を先に決めないと後から作り直しになります。計画の段階でそこを詰めさせてください。

## できあがりの条件

**自分の目で確認できるもの**だけを条件にしています。上から順に、1つずつ動かしながら進めてください。

1. **習慣を自由に追加できる** — 入力欄に名前を書いて追加すると、一覧に増える。数の上限はない
2. **今日やったかどうかをチェックできる** — 一覧の「今日」の欄で、やった/やっていないを切り替えられる
3. **過去7日間が一覧で見える** — 今日を右端として、直近7日ぶんの日付が横に並び、各日の達成有無が一目で分かる
4. **ブラウザを閉じても消えない** — 閉じて開き直しても、登録した習慣とチェックした記録が残っている
5. **習慣を削除できる** — 間違えて追加したものを消せる

## 制約

- **1つのHTMLファイルで完結させること。** 別ファイルのCSSやJavaScript、外部から読み込むライブラリは使わない
- インターネットに接続していなくても動くこと
- サーバーやデータベースは使わない。データはブラウザの中に保存する
- **保存が使えない環境でも画面が壊れないこと** — 保存機能が無効なブラウザ設定でも、アプリ自体は操作でき、保存できない旨が画面に出る

## やらなくていいこと

時間が余ったら考えても構いませんが、条件には含めません。

- 8日以上前の記録を見る機能
- 連続達成日数（ストリーク）やグラフの表示
- 複数人で共有する機能

## 動作確認のコツ

条件4は**必ずブラウザを閉じて開き直して確認してください。** 再読み込み（リロード）だけでは確認になりません。

また、条件3の日付が「今日を右端とした直近7日」になっているかは、日付の数字を実際に見て確かめてください。ここは間違えていても画面が壊れないので、見落としやすい条件です。
