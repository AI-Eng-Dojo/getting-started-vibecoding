# 中級課題B: 診断チャート

5つの質問に答えると、答えの組み合わせからタイプを判定して見せる診断コンテンツを作ります。

このフォルダをClaude Codeで開き、**まず実行計画だけ**を立てさせてください（指示文は[前編テキスト 4章](../../docs/01-part1.md)にあります）。計画を読んで納得してから実装させます。

## 作るもの

ブラウザで動く、1つのHTMLファイルで完結した「あなたに合う旅行先診断」。

テーマは旅行先でなくても構いません（好きな食べ物、向いている勉強法、など）。その場合も条件の数と構造は同じにしてください。

## できあがりの条件

**自分の目で確認できるもの**だけを条件にしています。上から順に、1つずつ動かしながら進めてください。

1. **質問が1問ずつ出る** — 5問を一度に並べず、答えると次の質問に切り替わる
2. **いま何問目かが分かる** — 「質問 3 / 5」のように、進み具合が画面に出る
3. **選択肢を押すだけで進む** — 入力欄への文字入力は不要。ボタンを押すだけで次へ行く
4. **答えの組み合わせで結果が変わる** — 結果は**4種類以上**用意し、単純な点数の合計ではなく**2つ以上の軸の組み合わせ**で判定する（例: 「活動的 / のんびり」×「街 / 自然」の2軸で4タイプ）
5. **結果にタイプ名と説明が出る** — タイプ名だけでなく、なぜそのタイプなのか・何がおすすめかが2〜3文で読める

## 制約

- **1つのHTMLファイルで完結させること。** 別ファイルのCSSやJavaScript、外部から読み込むライブラリは使わない
- インターネットに接続していなくても動くこと
- 質問文・選択肢・結果の文章は、Claudeに考えさせてよい

## やらなくていいこと

時間が余ったら考えても構いませんが、条件には含めません。

- 結果をSNSでシェアする機能
- 診断結果を保存して後から見返す機能
- 画像やイラストを使う

## 動作確認のコツ

**必ず2通り以上の答え方で試してください。** 全部1番目の選択肢を選んだときと、全部2番目を選んだときで、違う結果が出れば条件4が満たせています。同じ結果しか出ないなら、判定のロジックがまだ1軸です。
