# 詰め詰め

この計画のあらゆる側面について、共通理解に到達するまで徹底的にインタビューしてください。設計ツリーの枝を一本ずつ下り、決定同士の依存関係を一つずつ解消していきます。各質問には、あなたが推奨する回答も必ず添えてください。

質問は一度に一つだけにして、その回答を受け取ってから次へ進んでください。複数の質問をまとめて投げるのは相手を混乱させるだけです。

コードベースを調べればわかる**事実**は、質問せずに自分で確認してください。ただし**決定**はユーザーのものです。一つずつ提示し、回答を待ってください。

共通理解に到達したとユーザーが確認するまで、計画を実行に移してはいけません。
