# 仕様READMEワークシート（宿題用）

前半3で書いた[アイデアREADME](idea-readme.md)を、自作の `tsumete` で問い詰めたあとの**書き出し先**です。後半8にこの状態で持ってきてください。

**置き場所**: 自分のアプリのフォルダ（`⟨forkした実践用リポジトリ⟩/0901-yamada-app/README.md`）。前半3で作ったREADMEを、そのまま育てます。

> **先にSkillへ伝えること。** Grill Meを始める前に、次の3つを前提として渡してください。
> 1. ブラウザだけで動く構成にする（HTMLファイル1つが基本）
> 2. ログイン・課金・外部サービス連携は今回やらない
> 3. 後半2時間で作りきれる規模まで削る

## できること（3〜5個）

**「自分が操作して、目で確認できること」**の形で書きます。ここがそのまま後半の実装タスクになります。

- 悪い例:「タスクを管理できる」（何ができたら完成か分からない）
- 良い例:「入力欄にタスク名を入れてEnterを押すと、下の一覧に追加される」

```text
1.
2.
3.
4.
5.
```

## 今回やらないこと

Grill Meの過程で出た「それは今日はやらない」を、**捨てずにここへ書き写します。** 持ち帰って続けるときの出発点になります。

```text
-
-
```

## データをどう扱うか

```text
□ 残さない（ページを閉じたら消えてよい）
□ ブラウザに保存する（閉じても残る） ← 今日はここまでが範囲
```
