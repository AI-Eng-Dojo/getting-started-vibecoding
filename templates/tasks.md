# TASKS.md ワークシート（宿題用）

自作の `tsumete` で詰め終わったあと、やることを実装する順に並べるファイルです。後半の実装は、上から順にこれを消化していきます。

**置き場所**: `myapp` のルート（`TASKS.md`）。`README.md` と同じ場所です。

> 自作Skillに書き出しの指示を入れてあれば、詰め終わりに自動で出てきます。出てこなかったら、[docs/01-part1.md](../docs/01-part1.md) の宿題の節にあるプロンプトを貼ってください。

## 並べ方の3原則

| 原則 | なぜ |
|---|---|
| **1つは15分以内で終わる大きさ** | 後半は15分ごとに「動いてる? 保存した?」を確認します。それより大きいと確認できません |
| **それぞれに完了定義（画面のどこを見れば終わったと分かるか）を書く** | 自分の目で確認するのが今日の作法です。完了定義のないタスクは終われません |
| **上から順にやれば、途中で止まっても動くものが残る順番** | 時間切れは必ず起きます。仕上げを先にやると、切れたとき何も動きません |

## 書き方

```markdown
# やること

| # | やること | 完了定義 | 状態 |
|---|---|---|---|
| 1 | ⟨最小の画面を出す⟩ | ⟨ブラウザで開くと見出しが表示される⟩ | 未 |
| 2 | ⟨入力欄と追加ボタンを置く⟩ | ⟨文字を入れてボタンを押すと一覧に増える⟩ | 未 |
| 3 | ⟨閉じても消えないようにする⟩ | ⟨タブを閉じて開き直しても残っている⟩ | 未 |
| 4 | | | 未 |

## 今回やらないこと

- ⟨詰める過程で「今日はやらない」と決めたもの⟩
- ⟨理由も一行で⟩
```

## このファイルは自分の手で編集しません

作るのも、今日やる分を決めるのも、状態を更新するのも、すべてClaude Codeに頼みます。下は後半でそのまま使う頼み方です。

| したいこと | 頼み方 |
|---|---|
| 終わった分にチェックを入れる | `いま終わった分を、TASKS.md の状態に反映してください。` |
| 今日やる分を決める | `TASKS.md のやることを、MVP（今日やる分）と持ち帰る分に分けてください。` |
| 思いついたことを残す | `いま思いついた⟨…⟩を、TASKS.md の「今回やらないこと」に書き足してください。` |

**手で開いて書き換えたくなったら、それは指示で伝えるべきことです。** この教材でファイルを触るのは、最初から最後までClaude Codeの仕事です。

## 数が多くても構いません

10個を超えても問題ありません。後半の冒頭で「今日やる分」を決めます。残りは持ち帰って続けるための資産です。減らそうとして削るより、全部書いてから決めるほうが良い仕様になります。
