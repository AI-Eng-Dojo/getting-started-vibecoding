# レビュー・改善プロンプトテンプレート（後半10 ハンズオン⑦用）

そのまま貼り付けて使えます。前半5で触れたSecurity Review Skillなどがあれば、先にそれを呼んでから使うのもおすすめです。ワークショップ後も、何かを実装するたびにこのテンプレが使えます。

```text
実装したコードをレビューしてください。次を確認し、見つかった問題は直してください。
1. 簡単なテスト（動作確認できる範囲でよい）
2. セキュリティ上の問題（秘密情報の直書き、入力の未検証な使用など）
3. 読みにくい・重複しているコードのリファクタリング
4. 改善したほうがよい点の提案
5. 今日時間切れで残った場合、次に実装すべきことのリスト
```

> **「できました」を鵜呑みにしない。** Claudeは実際には確認せず「できています」と答えてしまうことがあります。最後は必ず**自分の目**でレビュー結果と動作を確認してください。あなたの確認が最終権限です。
