# アイデアREADMEワークシート（前半3 自分が作りたいものを考える用）

壁打ちで進めるアイデアを一つ選んでから、⟨ ⟩の中を自分の言葉で埋めてください。書き方の詳細は [docs/01-part1.md](../docs/01-part1.md) の3章にあります。埋め終わったら、この内容をそのままClaude Codeに渡して「これをREADME.mdにしてください」と頼めます。

## 何を作りたいか（一言で）

```text
⟨                                          ⟩
```

- 悪い例:「家計簿アプリ」（名詞だけ。何ができたら完成か分からない）
- 良い例:「レシートの金額を入力すると、今月あといくら使えるかが分かるアプリ」

## 誰が使うか

```text
⟨                                          ⟩
```

## 何ができればいいか（3〜5個）

**自分が操作して目で確認できること**を書くと、あとで実装できたかどうかの判断がしやすくなります。

```text
1.
2.
3.
```

## どんな体験にしたいか

使ったときに、どんな気持ちになってほしいか・何が楽になってほしいかを書いてください。

```text
⟨                                          ⟩
```

## デモで体験を確かめる

4点を書いたら、前半3の手順で中心になる操作を一つだけデモにし、実際に触ってください。
気づいたことを「どんな体験にしたいか」へ書き戻したら、デモ用のファイルだけを削除します。
アイデアと体験を確認したREADMEは手元にコミットし、プッシュは後半10のセキュリティレビュー後に行います。
