# Grill Me系エージェントスキルの雛形（前半4の自作用）

前半4では、問い詰めから実装資料の作成までを担う `tsumete` と、決まった用語や決定を書き残す `ddd` の二つを作ります。この雛形は `tsumete` 用です。`ddd` の完成例は [docs/01-part1.md](../docs/01-part1.md) にあります。

`tsumete` は長い問い詰めを始める入口なので、Claudeの判断で動き出さないよう `disable-model-invocation: true` を設定します。開始するときは `/tsumete` と入力します。

そのまま使わず、`⟨ ⟩` の部分を自分の言葉で書き換えてから `SKILL.md` として保存してください。**丸写しでは、宿題・後半で自分が欲しい質問をしてくれません。**

```markdown
---
name: tsumete
description: ⟨計画や仕様を問い詰め、README.mdとTASKS.mdにまとめることを一文で説明する⟩
disable-model-invocation: true
---

# 詰めて

対象は、いま開いているフォルダの README.md です。まず読んでから始めてください。

この計画のあらゆる側面について、共通理解に到達するまで徹底的に質問してください。
質問は一度に一つだけにし、回答を受け取ってから次へ進んでください。
各質問には、あなたが推奨する回答も必ず添えてください。
調べれば分かる事実は質問せず自分で確認し、決定はユーザーに委ねてください。

会話の中で用語の意味が確定したら、`ddd`を使って CONTEXT.md に書き足してください。
あとから変更するのが大変な決定が出たら、`ddd`を使って docs/adr/ に短い決定記録（ADR）として残してください。
まとめて後回しにせず、決まった瞬間に書き残してください。
自動で記録されなかった場合は、会話の中で`ddd`に記録するよう指示してください。

最後に、次の2つを書き出してください。

1. 仕様を README.md に
   - 何を作るか／誰が使うか／どんな体験にしたいか／できること
   - 今回やらないことと、その理由
   - アプリ全体のできあがりを確かめる完成判定

2. 実装する順の「やること」を TASKS.md に
   - 「状態／やること／完了定義」の3列の表にし、状態はすべて「未」で始める
   - 1つのやることは15分以内で終わる大きさにする
   - 完了定義には、画面のどこを見れば終わったと分かるかを書く
   - 上から順に進めれば、途中で止まっても動くものが残る順番にする
```

## 雛形に含めた指示

この雛形では、問い詰めの進め方と成果物の出力を、どちらも `tsumete` に書いています。用語や後戻りしにくい決定を別ファイルに残す処理だけを `ddd` に任せます。

`README.md` と `TASKS.md` はそれぞれ役割が違います。`TASKS.md` の完了定義は一件ごとの終わりを確かめるもので、`README.md` の完成判定はアプリ全体のできあがりを確かめるものです。

## 完成例

以前の `tsumetsume` の完成例は、現在の構成では `tsumete` に統合しています。完成形は [skills/tsumete/SKILL.md](../skills/tsumete/SKILL.md)、記録用の `ddd` は [skills/ddd/SKILL.md](../skills/ddd/SKILL.md) を参照してください。

## 保存先

```text
myapp/.claude/skills/tsumete/SKILL.md   ← プロジェクトレベル（この講座ではこちら）
~/.claude/skills/tsumete/SKILL.md       ← ユーザーレベル（この講座では使わない）
```

自分でフォルダを掘る必要はありません。書いた中身をそのまま貼って、Claude Codeに保存させてください。

```text
次の内容を、このリポジトリ（myapp）の .claude/skills/tsumete/SKILL.md として保存してください。
フォルダが無ければ作ってください。

⟨ここに、自分で書いたSKILL.mdの中身をそのまま貼る⟩
```

この講座では、宿題も後半も `myapp` で作業するので、**プロジェクトレベル**（`myapp` の `.claude/skills/`）に置きます。別のプロジェクトでも使いたくなったら、そのプロジェクトの `.claude/skills/` にコピーしてください。

## 動作確認の手順

1. `myapp/.claude/skills/tsumete/SKILL.md` に保存する。置き場所自体を初めて作ったときはClaude Codeを再起動する
2. 既存の置き場所に追加した内容はそのまま反映される。候補に出なければ `/reload-skills`、再起動の順に試す
3. `/tsumete` と入力し、一問ずつ質問が返ってくることを確かめる。用語や決定が確定した場合は `ddd` が記録すること、最後に `README.md` と `TASKS.md` が書き出されることも確認する
4. 質問や成果物を直したい場合は本文を変更し、`/clear` で旧版の指示が残る会話を切ってから試す

同じ名前のエージェントスキルがユーザーレベルにあると、そちらが優先されます。意図した版が動かない場合は、名前と保存先も確認してください。
