# Grill Me Skill 雛形（前半4 自作Skill用）

前半4「Grill Me系エージェントスキルを自作する」で使う出発点です。前半4では `tsumetsume`・`ddd`・`tsumete` の3つを作りますが、この雛形は1つ目の `tsumetsume`（一問ずつ問い詰める部分）専用です。残り2つのサンプルは [docs/01-part1.md](../docs/01-part1.md) 本文にあります。

`tsumetsume` は中身を持つスキルなので、**`description` には「いつ使うか」を必ず書きます。** Claudeはそこを読んで自分で呼ぶかどうかを判断します。

そのまま使わず、⟨ ⟩の部分を自分の言葉で書き換えてから `SKILL.md` として保存してください。**丸写しでは、宿題・後半で自分が欲しい質問をしてくれません。**

```markdown
---
name: ⟨skillの名前・英数字とハイフンのみ⟩
description: ⟨このSkillが何をするか、いつ使うべきかを一文で。Claudeはここだけを見て使うかどうか判断します⟩
---

# ⟨Skillのタイトル⟩

⟨ここから、質問の仕方そのものを指示として書きます。以下は書き方のヒントです⟩

- 一度に質問する数（1つずつか、まとめてか）
- 何について聞くか（誰が使うか／何ができれば完成か／どこまでの範囲を今回はやらないか、など）
- 事実確認（自分で調べられること）と、決定（ユーザーに委ねるべきこと）をどう区別するか
- どこまで厳しく・何往復くらい問い詰めるか
- **質問の最後に何を出力してほしいか** ← ここがいちばん効きます。次項へ
```

## 最後に「何を出力させるか」を必ず書く

ここを書かないと、詰めた結果は会話の中に消えます。画面を閉じたら終わりです。

宿題では次の2つを出力させてください。この2行を自分のSkillの本文に入れておくと、宿題の終わりに自動で出てきます。

```text
最後に、次の2つを書き出してください。

1. 具体化された仕様を README.md に
   （何を作るか／誰が使うか／できること／今回やらないこと／完成判定）

2. 実装する順に「やること」の一覧を TASKS.md に
   - 1つのやることは15分以内で終わる大きさにする
   - それぞれに完了定義（画面のどこを見れば終わったと分かるか）を書く
   - 上から順にやれば、途中で止まっても動くものが残る順番にする
```

3つ目の「途中で止まっても動くものが残る順番」が効きます。**印刷や仕上げを先にやると、時間切れのときに何も動きません。**

## 保存先

```
<プロジェクト>/.claude/skills/⟨skillの名前⟩/SKILL.md   ← プロジェクトレベル
~/.claude/skills/⟨skillの名前⟩/SKILL.md                ← ユーザーレベル
```

自分でフォルダを掘る必要はありません。書いた中身をそのまま貼って、Claude Codeに保存させてください。

```text
次の内容を ~/.claude/skills/⟨skillの名前⟩/SKILL.md として保存してください。
フォルダが無ければ作ってください。

⟨ここに、自分で書いたSKILL.mdの中身をそのまま貼る⟩
```

宿題・後半でも使い続けるので、**ユーザーレベル**に置いておくのがおすすめです（自分の作法はユーザーレベル、チームの決まりごとはプロジェクトレベル）。

## 動作確認の手順

1. 保存する
2. 別のフォルダでClaude Codeを開き直す（すでに開いている場合は一度終了して開き直す）
3. `description` に書いた呼び出し方（例:「詰め詰め」）で呼んでみる
4. 意図通りの質問が返ってこなければ、`description` または本文を直して2〜3へ戻る

## サンプル（詰め詰め）

書き方に迷ったら、この完成例を見てから自分の言葉で書き直してください。

```markdown
---
name: tsumetsume
description: 計画や仕様を実装前に徹底的に問い詰めて磨き上げる。実装前に計画を揺さぶりたいとき、「詰め詰め」と頼まれたときに使う。
---

# 詰め詰め

この計画のあらゆる側面について、共通理解に到達するまで徹底的にインタビューしてください。
質問は一度に一つだけにし、回答を受け取ってから次へ進んでください。
各質問には、あなたが推奨する回答も必ず添えてください。
調べれば分かる**事実**は質問せず自分で確認し、**決定**はユーザーに委ねてください。
```
